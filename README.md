# Particle System
https://github.com/user-attachments/assets/6bcea954-0b69-4842-84c1-ce7bac3d8c79
A low level OpenGL/C++ particle system project with Imgui UI for interactively adjusting parameters and viewing results in real time. 
It simulates particles with gravity, aerodynamic drag, and ground collisions. 

Particles are continuously created at an adjustable rate, have variable initial positions, velocities, and life spans, and disappear when their life span reaches zero. 
Particles can be rendered as small spheres or sprites, with adjustable gravity, air density, drag coefficient, particle radius, collision elasticity, and friction.
